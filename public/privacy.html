นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด: 6 กันยายน 2569

นโยบายฉบับนี้อธิบายว่า Milo Bot เก็บข้อมูลอะไรบ้างจากการใช้งานของคุณและเซิร์ฟเวอร์ Discord ที่เชิญบอทเข้าไป ใช้ข้อมูลนั้นอย่างไร และคุณติดต่อเราเพื่อจัดการข้อมูลของคุณได้อย่างไร

1. ข้อมูลที่เราเก็บ

ประเภทข้อมูลใช้เพื่ออะไร
Guild ID (รหัสเซิร์ฟเวอร์ Discord) ผูกการตั้งค่าต่างๆ (การ์ดต้อนรับ, ฟอนต์, สถานะพรีเมียม) กับเซิร์ฟเวอร์ของคุณ
Discord User ID ของผู้สมัครพรีเมียม ใช้ส่งข้อความแจ้งเตือน (DM) เมื่อสมัคร/ต่ออายุพรีเมียมสำเร็จ
ไฟล์ฟอนต์และรูปภาพที่อัปโหลด ใช้วาดการ์ดต้อนรับ/บอกลาตามที่แต่ละเซิร์ฟตั้งค่าไว้ เก็บแยกตาม guild ID
ข้อมูลการสมัครสมาชิก (Stripe Customer ID, Subscription ID, วันครบรอบบิล) ใช้ตรวจสอบสถานะพรีเมียมและจัดการการต่ออายุ/ยกเลิก

2. ข้อมูลที่เราไม่ได้เก็บ

  • เราไม่เก็บข้อมูลบัตรเครดิต/เดบิตของคุณเลย — การชำระเงินทั้งหมดประมวลผลโดย Stripe โดยตรง เราเห็นแค่ผลลัพธ์ว่าจ่ายสำเร็จหรือไม่เท่านั้น
  • เว็บไซต์นี้ไม่มีระบบสมัครสมาชิก/เข้าสู่ระบบ (login) ของตัวเอง ไม่มีการเก็บรหัสผ่านใดๆ

3. เราแชร์ข้อมูลกับใครบ้าง

  • Discord — ในฐานะแพลตฟอร์มที่บอทรันอยู่ (การส่งข้อความ, การอ่านข้อมูลเซิร์ฟเวอร์ ทำผ่าน Discord API ตามสิทธิ์ที่คุณอนุญาตตอนเชิญบอท)
  • Stripe — สำหรับประมวลผลการชำระเงินและจัดการการสมัครสมาชิก (ดูนโยบายความเป็นส่วนตัวของ Stripe เพิ่มเติมได้ที่เว็บไซต์ Stripe)
  • เราไม่ขายหรือให้เช่าข้อมูลของคุณแก่บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาดใดๆ

4. ระยะเวลาการเก็บข้อมูลและการลบ

ข้อมูลการตั้งค่าของเซิร์ฟเวอร์ (การ์ดต้อนรับ, ฟอนต์, ระบบยศ ฯลฯ) จะถูกเก็บไว้ตราบเท่าที่บอทยังอยู่ในเซิร์ฟเวอร์นั้น หากต้องการให้ลบข้อมูลทั้งหมดของเซิร์ฟเวอร์คุณ (เช่น หลังนำบอทออกจากเซิร์ฟแล้ว) หรือมีคำถามเกี่ยวกับข้อมูลส่วนตัว สามารถติดต่อได้ที่อีเมลด้านล่าง เราจะดำเนินการลบข้อมูลตามคำขอภายในเวลาอันสมควร

5. ความปลอดภัยของข้อมูล

ข้อมูลถูกเก็บไว้บนเซิร์ฟเวอร์ของผู้ให้บริการโฮสติ้ง (Railway) และเข้าถึงได้เฉพาะทีมงานผู้ดูแลบอทเท่านั้น เราพยายามอย่างเต็มที่ในการดูแลความปลอดภัยของข้อมูล แต่ไม่มีระบบใดที่ปลอดภัย 100% เราจะแจ้งให้ทราบ หากพบเหตุการณ์ที่กระทบต่อความปลอดภัยของข้อมูลอย่างมีนัยสำคัญ

6. เด็กและเยาวชน

บริการนี้ให้บริการผ่านแพลตฟอร์ม Discord ซึ่งกำหนดอายุขั้นต่ำของผู้ใช้งานไว้ตามข้อกำหนดของ Discord เอง เราไม่ได้เก็บข้อมูลเพิ่มเติมนอกเหนือจากที่ Discord API ให้มาตามสิทธิ์ที่เซิร์ฟเวอร์อนุญาต

7. การเปลี่ยนแปลงนโยบาย

นโยบายฉบับนี้อาจมีการปรับปรุงเป็นครั้งคราวเพื่อให้สอดคล้องกับฟีเจอร์ใหม่ๆ ของบอท การเปลี่ยนแปลงจะมีผล ทันทีที่เผยแพร่บนหน้านี้
