รวมวิธีใช้คำสั่งทุกตัวแบบละเอียด ทีละขั้นตอน — เลือกหัวข้อด้านล่าง หรือเลื่อนดูได้เลย

🎨 ตกแต่งเซิร์ฟ

ค่าเริ่มต้นเปิดให้สมาชิกทุกคนใช้ได้ — ถ้าอยากจำกัดแค่แอดมิน ไปตั้งเองได้ที่ Discord Server Settings → Integrations → Milo Bot
/welcome-setup ใช้ได้ทุกคน

ตั้งค่าการ์ดต้อนรับสมาชิกใหม่ — โพสต์การ์ดรูปสวยๆ อัตโนมัติทุกครั้งที่มีคนเข้าเซิร์ฟ

วิธีใช้
  1. พิมพ์ /welcome-setup เฉยๆ ไม่มีตัวเลือกให้กรอกตรงนี้ — บอทจะเด้งแผงควบคุมเป็นปุ่มกดมาให้ทันที (เห็นแค่คนที่พิมพ์คำสั่ง)
  2. กดปุ่มเลือกห้องที่จะโพสต์การ์ด, พื้นหลัง (รูปของตัวเอง, สีพื้น หรือ GIF ถ้าเป็นพรีเมียม), ข้อความต้อนรับ, ฟอนต์
  3. เปิด/ปิดการใช้งานได้จากปุ่มเดียวกัน — ถ้ายังไม่เลือกห้อง การ์ดจะยังไม่โพสต์ไปไหน
/goodbye-setup ใช้ได้ทุกคน

ตั้งค่าการ์ดอำลาสมาชิกที่ออกจากเซิร์ฟ — ทำงานแบบเดียวกับ /welcome-setup เป๊ะๆ แค่ฝั่ง "ออก" แทน "เข้า"

วิธีใช้
  1. พิมพ์ /goodbye-setup เฉยๆ — เจอแผงควบคุมแบบเดียวกับ welcome
  2. เลือกห้อง, พื้นหลัง, ข้อความอำลา, ฟอนต์ แล้วเปิดใช้งาน
/role-setup ใช้ได้ทุกคน

สร้างระบบแจกยศอัตโนมัติ — สมาชิกกดรับยศเอง ไม่ต้องรอแอดมินแจกทีละคน

  • /role-setup new — สร้างชุดใหม่ (ตั้งชื่อ + เลือกรูปแบบ: menu ดรอปดาวน์, button ปุ่มกด, reaction กด emoji — เมนู/ปุ่มเป็นของพรีเมียม ฟรีใช้ได้แค่ reaction สูงสุด 2 ยศ)
  • /role-setup edit — เปิดชุดเดิมมาแก้ (เพิ่ม/ลดยศ, เปลี่ยน emoji ฯลฯ)
  • /role-setup list — ดูรายชื่อชุดที่สร้างไว้ทั้งหมดในเซิร์ฟนี้
  • /role-setup delete — ลบชุดที่ไม่ใช้แล้ว
วิธีใช้ (สร้างใหม่)
  1. พิมพ์ /role-setup new ตั้งชื่อ + เลือกรูปแบบ
  2. กดปุ่มในแผงควบคุมเพื่อเพิ่มยศแต่ละอัน (เลือกยศจริงของเซิร์ฟ + ข้อความ/emoji ของปุ่มนั้น)
  3. กดโพสต์ข้อความลงห้องที่ต้องการ — สมาชิกกด/เลือก/reply ได้รับยศเองทันที

บอทต้องมีสิทธิ์ Manage Roles และยศของบอทต้องอยู่ "สูงกว่า" ยศที่จะแจก ไม่งั้นแจกไม่ได้ (ข้อจำกัดของ Discord เอง ไม่ใช่บั๊ก)

/builder ใช้ได้ทุกคน

ตัวจัดวางข้อความ/ประกาศเอง ไม่ต้องเขียนโค้ด — คลิกเพิ่ม block (ข้อความ, รูป, เส้นคั่น, ปุ่มลิงก์/ยศ/ห้อง) แล้วโพสต์เป็นข้อความสวยๆ

  • /builder new — สร้างฉบับร่างใหม่ (ตั้งชื่อ) — ฟรีมีได้ 1 ฉบับ/เซิร์ฟ พรีเมียมไม่จำกัด
  • /builder edit — เปิดฉบับร่างเดิมมาแก้ต่อ
  • /builder list — ดูรายชื่อฉบับร่างทั้งหมด
  • /builder delete — ลบฉบับร่างที่ไม่ใช้แล้ว
วิธีใช้ (สร้างใหม่)
  1. พิมพ์ /builder new ตั้งชื่อฉบับร่าง
  2. กดปุ่มเพิ่ม block ทีละอัน แล้วกรอก/อัปโหลดเนื้อหาของ block นั้น
  3. กดโพสต์ลงห้องที่ต้องการเมื่อพอใจแล้ว — แก้ต่อได้ตลอดผ่าน /builder edit
/fonts ใช้ได้ทุกคน

อัปโหลดฟอนต์ของตัวเอง (.ttf/.otf) ไว้ใช้กับการ์ด welcome/goodbye และยศของเซิร์ฟนี้

  • /fonts list — ดูฟอนต์ทั้งหมด (ฟอนต์มาตรฐานของบอท + ที่อัปโหลดเอง) เลือกลบฟอนต์ที่อัปโหลดเองได้
  • /fonts upload — แนบไฟล์ฟอนต์ .ttf หรือ .otf เพื่ออัปโหลด (สูงสุด 20 ฟอนต์/เซิร์ฟ)
/upload-image ใช้ได้ทุกคน

อัปโหลดรูปเพื่อเอา "ลิงก์ถาวร" มาใช้กับคำสั่งอื่นที่ต้องกรอกลิงก์รูป (เช่นพื้นหลังการ์ด)

วิธีใช้
  1. พิมพ์ /upload-image แล้วแนบไฟล์รูป (.png .jpg .jpeg .webp .gif)
  2. บอทตอบลิงก์กลับมา — ก๊อปลิงก์นั้นไปวางในช่องที่ต้องการได้เลย ลิงก์นี้ไม่มีวันหมดอายุ

⚙️ ตั้งค่าทั่วไป

/language ต้องมี Manage Server

ตั้งภาษาที่บอทใช้ตอบในเซิร์ฟนี้ — เลือกได้ระหว่าง English กับ ไทย มีผลกับทุกข้อความที่บอทตอบในเซิร์ฟนี้ตั้งแต่ตั้งค่า

/premium ต้องมี Manage Server

จัดการสถานะพรีเมียมของเซิร์ฟนี้ — ดูสถานะปัจจุบัน, สมัคร/ต่ออายุ, หรือจัดการการสมัครสมาชิก

/help ใช้ได้ทุกคน

โชว์รายการคำสั่งทั้งหมด พร้อมตัวอย่างสิ่งที่บอทสร้างได้จริง — เหมาะเป็นจุดเริ่มต้นสำหรับคนที่เพิ่งเชิญบอทเข้าเซิร์ฟ

/ping ใช้ได้ทุกคน

เช็กความหน่วง (latency) ของบอทตอนนี้ — ใช้ตอนสงสัยว่าบอทตอบช้าผิดปกติหรือเปล่า

🛒 Marketplace

/marketplace ใช้ได้ทุกคน

เปิดร้านขายของตกแต่ง/บริการสาย Discord ของตัวเอง ผ่านตลาดกลางบนหน้าเว็บ /marketplace — ลงประกาศจากดิสคอร์ด แล้วไปโชว์ขายอยู่บนหน้าเว็บให้คนอื่นซื้อได้

  • /marketplace sell — ลงประกาศขายใหม่ (ชื่อ, ราคา, คำอธิบาย, หมวดหมู่, รูปปก, และของที่จะส่ง — ไฟล์ดิจิทัล/ลิงก์ระบบหรือเทมเพลต/รหัสตั้งค่า Milo Bot — เลือกได้จากหน้าเว็บ Dashboard ด้วย ไม่ต้องกรอกทุกอย่างจากดิสคอร์ด)
  • /marketplace mylistings — ดูประกาศขายทั้งหมดของตัวเอง
  • /marketplace remove — ปิดประกาศ (ขายหมด/ไม่ขายแล้ว แต่ยังเปิดขายใหม่ได้ทีหลัง)
  • /marketplace markselling — เปิดประกาศที่เคยปิดไว้ให้กลับมาขายอีกครั้ง
  • /marketplace setpromptpay — ตั้ง/แก้เบอร์พร้อมเพย์รับเงิน (สำหรับผู้ขายในไทย)
  • /marketplace setpaymentlink — ตั้ง/แก้ลิงก์รับเงินสากล เช่น PayPal.me (สำหรับผู้ขายต่างชาติ)

บอทไม่แตะเงินของใครเลย — ผู้ซื้อจ่ายตรงเข้าบัญชีผู้ขาย (สแกน QR หรือกดลิงก์) บอทแค่ช่วยแจ้ง/ส่งของต่อให้อัตโนมัติหลังผู้ขายกดยืนยันว่าได้รับเงินแล้ว

เจาะลึก — ฟีเจอร์ที่คนงงกันบ่อยที่สุด

/milo export-config  &  /milo import-config ต้องมี Administrator

ใช้สำหรับ "ส่งต่อชุดตั้งค่า Milo Bot" ของเซิร์ฟตัวเองให้คนอื่นเอาไปใช้ต่อได้ทันที — คล้ายการขายเทมเพลต Canva ที่คนซื้อกด Import แล้วได้ของพร้อมใช้เลย โดยส่งผ่านตลาด /marketplace ด้านบน

🧑‍💻 ฝั่งคนขาย (ผู้สร้างชุดตั้งค่า)

ทำในเซิร์ฟที่ตั้งค่าไว้สวยแล้ว ก่อนเอาไปลงขาย

  1. ตั้งค่าการ์ด Welcome/Goodbye, Role setup, และ/หรือ Builder ในเซิร์ฟตัวเองให้เรียบร้อยตามที่จะขาย
  2. พิมพ์ /milo export-config ในเซิร์ฟนั้น (ต้องมีสิทธิ์ Administrator) — บอทจะรวบรวม 3 อย่างนี้เป็นรหัสเดียว เช่น MILO-7K2X9QAB
  3. บอทตอบ (เห็นแค่คนพิมพ์คำสั่ง) สรุปว่ารหัสนี้มีอะไรติดไปบ้าง — เช็คให้ตรงกับที่ตั้งใจขาย
  4. เอารหัสนี้ไปกรอกในช่อง "รหัสการตั้งค่า Milo Bot" ตอนลงขายด้วย /marketplace sell (หรือจากหน้าเว็บ Dashboard)

🛍️ ฝั่งคนซื้อ (ผู้รับชุดตั้งค่า)

ทำหลังจ่ายเงินซื้อสำเร็จแล้ว

  1. จ่ายเงินซื้อสินค้าบนหน้าเว็บ Marketplace ตามปกติ
  2. บอทส่งรหัส (เช่น MILO-7K2X9QAB) มาทาง DM ให้ทันทีหลังผู้ขายกดยืนยันว่าได้รับเงินแล้ว
  3. ไปที่เซิร์ฟของตัวเอง พิมพ์ /milo import-config แล้ววางรหัสที่ได้ในช่อง code (ต้องมีสิทธิ์ Administrator ของเซิร์ฟนั้น)
  4. บอทติดตั้งการ์ด/role setup/builder ที่ติดมากับรหัสให้ทันที พร้อมสรุปว่าติดตั้งอะไรไปบ้าง

⚠️ ข้อควรรู้ก่อนใช้งานจริง

รหัสแต่ละอัน ใช้ได้ครั้งเดียวเท่านั้น — import ไปแล้วรหัสนั้นจะใช้ซ้ำไม่ได้อีก (กันขายรหัสเดียวซ้ำแบบไม่จำกัด)

ยศ/ห้องที่ติดมากับ role setup และ builder (ปุ่มแจกยศ, ปุ่มลิงก์ห้อง) ยังเป็นของเซิร์ฟผู้ขายเดิม ใช้งานไม่ได้จนกว่าผู้ซื้อจะไปกำหนดยศ/ห้องของเซิร์ฟตัวเองใหม่เองผ่าน /role-setup edit / /builder edit

ห้องโพสต์การ์ด Welcome/Goodbye ก็ไม่ติดมาด้วย (ตั้งใจ) — ผู้ซื้อต้องเลือกห้องของตัวเองใหม่เสมอหลัง import

ถ้าเซิร์ฟผู้ซื้อเป็นแผนฟรี ระบบจะตัดเฉพาะส่วนที่แผนฟรีทำไม่ได้อยู่แล้วให้อัตโนมัติ (เช่น role setup แบบเมนู/ปุ่ม, reaction เกิน 2 ยศ) ไม่ทำให้ import ล้มเหลวทั้งหมด
